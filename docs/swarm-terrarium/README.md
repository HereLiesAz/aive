# Swarm Terrarium Design Brief

The authoritative formatted brief is committed beside this index as `Haive_Swarm_Terrarium_Design_Brief.docx`.

The terrarium turns workflow execution into a living, teachable artificial-life system: procedurally generated cel-shaded swarm agents behave as animated neuron-like creatures, while the canonical Haive logo character serves as the orchestrator/queen. Agents have stable non-colour identities, independent lightweight behavior loops, visible birth/delegation, synaptic transfer/conference interactions, and drag/drop workflow authoring.
