# The Haive brand assets

This directory contains the canonical brand sources for The Haive.

## Canonical sources

- `haive_logo.png` — current color logo and the single source for Desktop/Web icon generation
- `haive_monochrome.png` — current monochrome logo
- `haive_splash.gif` — animated startup/loading treatment
- `haive_animation1.mp4` / `haive_animation2.mp4` — extended motion assets

Desktop and Web icon sizes are generated deterministically from `haive_logo.png` by the Gradle brand pipeline. Android branding is maintained separately and is not regenerated by that pipeline.

Desktop `.png`, `.ico`, and `.icns` files are build outputs under `desktopApp/build/generated/brand/desktop`; Web favicon/PWA sizes are build outputs under `webApp/build/generated/brand/web`. Stale checked-in platform derivatives are intentionally not retained.
