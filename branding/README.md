# The Aive brand assets

This directory contains the canonical brand sources for The Aive.

## Canonical sources

- `aive_logo.png` — current color logo and icon source
- `aive_monochrome.png` — current monochrome logo

Desktop/Web icon sizes are generated deterministically from `aive_logo.png` by the Gradle brand pipeline.

Generated platform derivatives live under each module's `build/generated/brand` tree and are not canonical source files. Desktop and Web consume those generated assets.
